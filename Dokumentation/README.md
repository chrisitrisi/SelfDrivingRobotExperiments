## 📁 Ordnerübersicht

| Ordner | Inhalt & Verwendungszweck |
| :--- | :--- |
| **`01_Antrag`** | Offizieller Antrag aus dem aba-Portal (PDF), genehmigte Aufgabenstellung, Meilensteine. |
| **`02_Diplomarbeit`** | Die schriftliche Diplomarbeit (Word `.docx` oder LaTeX `.tex`) inkl. Unterordner `Bilder/` für Grafiken. |
| **`03_Praesentationen`** | Alle Folien (PPTX/PDF): VTP (Vorgezogene Teilprüfung), Zwischenberichte und Abschlusspräsentation. |
| **`04_Plakat`** | A0-Diplomarbeitsplakat für Tag der offenen Tür & Aula-Ausstellung (BULME PPTx-Vorlage). |
| **`05_Datenblaetter`** | Technische PDFs aller verbauten Komponenten (Sensoren, ESP32, Motortreiber, Schaltpläne). |
| **`06_Protokolle`** | Laufende Besprechungsnotizen mit den Betreuungslehrern (Nachweis für die Betreuung). |
| **`07_Fotos_und_Videos`** | Bilder vom Roboter, Baufortschritt, 3D-Druck, Bestückung und Videos von Testfahrten. |
| **`08_Messungen_und_Tests`** | Testergebnisse, Sensorgenauigkeit, Kalibrierdaten, Diagramme und Fahrversuche. |
| **`09_Vorlagen`** | Originale, unveränderte Vorlagen der HTL BULME (LaTeX, Word, PowerPoint, Plakat). |

## 📌 Wichtige BULME-Namenskonventionen

Bei offiziellen Abgaben verlangt die BULME exakte Dateinamen:

* **Diplomarbeit & Abschlusspräsentation (PDF):**  
  `Jahr-Klasse-Betreuerkurzzeichen-Name1.Name2.Name3.Name4-Projektname.pdf`  
  *Beispiel:* `2027-5AHEL-XX-Nachname1.Nachname2.Nachname3.Nachname4-SelfDrivingRobot.pdf`

* **Plakat (PowerPoint):**  
  `Klasse - Nachnamen - Kurztitel.pptx`  
  *Beispiel:* `5AHEL - Nachname1 Nachname2 Nachname3 Nachname4 - SelfDrivingRobot.pptx`
