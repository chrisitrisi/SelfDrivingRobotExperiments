# Fertigungsdaten Liniensensor R3.1 (JLCPCB)

Erzeugt am 26.11.2026 mit KiCad 10.0.7.

- `Gerber_JLC_Liniensensor.zip`: Gerber (2 Lagen) und Bohrdaten zum Hochladen.
- `BOM_JLC.csv` / `CPL_JLC.csv`: 31 SMD-Teile, alle oben.
- `Selbst_bestuecken.csv`: die sechs CNY70 (U1–U6, unten) selbst einlöten, mit 0,5-mm-Abstandslehre (optische Fläche 2 mm über Boden).
- Bestelloptionen: 2 Lagen, FR4, 1,6 mm, 1 oz.
- In der JLC-Vorschau prüfen: Q1/Q2 (BCX56-16, SOT-89) **Pin 1 = Emitter**, Pin 3 = Basis. Das ausgewählte LCSC-Teil muss diese Belegung haben (NXP/Diodes-Standard).
